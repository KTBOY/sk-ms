## 三、分工与角色构成
1. **世界观与设定集架构师**：资料整合提炼、HTML 设定集制作、主线大纲扩展规划（201–1200 章）。
2. **小说主笔**：正文续写与文案撰写（职业网文作家定位，遵循 yrdy/AGENTS.md 规则＋setting/风格规则补充.md）。
3. **连贯性与伏笔巡检员**：章节逻辑审查、战力/设定 BUG 监测、伏笔台账维护、异常熔断。
4. **主控 Agent（皮皮）**：任务管道编排、参数落盘、定时任务创建与状态同步，不直接参与创作。

## 四、交互与交付模式
1. **资料承接**：一切创作以用户上传资料为唯一事实源。
2. **生产（日更运行中）**：手动口令触发日更编排（熔断自检→定章号→插队创建「正文续写＋质量审计」子任务→后台顺序执行→主控验收后交付当日正文）；巡检员逐批审计并更新台账。
3. **异常干预**：严重逻辑冲突或伏笔挂起时熔断，向用户提交决策选项。
4. **完结阶段**：全书 1200 章达标且伏笔清零后，产出终章与全书整编版（合并用户已有正文＋团队续写正文）。
