# 《九州烟云》风格规则补充（团队执行规则）

> **效力**：与 `yrdy/AGENTS.md` 写作规则并行生效的增量规则，由用户直接指令产生。与 AGENTS.md 冲突时以本补充规则＋用户最新指令为准。规则一仅约束标点风格；规则二至六为写作技法增量，不改任何设定数据源，只约束正文写法与润色手法。
> **生效时间**：规则一，2026-09-08 14:08（用户群内指令）。规则二至七，2026-09-10（用户指令：自「小说创作助手（my-novel-writer）」技能吸收可借鉴技法，合并入本文件；不采纳项见规则七）。

## 规则一：全文禁用破折号

1. **禁用符号**：破折号"——"及单横线"—"在正文、大纲、文案、简报、报告、设定集等**一切团队产出文本中一律禁用**。
2. **替代方案**：原破折号承担的语义按语境改写：
   - 解释/补充说明 → 改用逗号、冒号或拆句；
   - 语音延长/停顿 → 改用省略号"……"或改写句式；
   - 话题转折 → 拆为两句，或用"只是""可是""不料"等转折词衔接；
   - 对话中被打断 → 可改用省略号，或按 AGENTS.md 既有对话体例处理。
3. **改写底线**：只动标点与句式，不改剧情事实、人物台词语义与人设语气；正文改写后单章字数须保持在 1800–2600 区间。
4. **适用范围**：
   - 增量文本：日更正文、审计报告、台账、文案、设定集更新等自生效时点起一律禁用；
   - 存量文本：团队已产出的第 54–56 章终版、扩展大纲、简介文案、设定集等做一次性专项清理。
5. **审计要求**：质量审计将"破折号零残留"全文检索列为固定检查项（grep "——" 与 "—"）。

## 规则二：爽点密度与章节节奏

1. **爽点密度**：每章至少 1 个小爽点。候选类型：打脸、破境、得宝或得技、计谋得逞、收服人心、身份反转、实力被验证。爽点必须从已铺垫的因果中生长，伏笔回收本身即算爽点；不用无代价的"天降好运"。
2. **章节三段节奏**：开篇快速切入冲突，禁止慢启；中段铺垫与博弈，维持悬念；结尾留钩。连载没有"第一章"，但每卷卷首等同二次开书：卷开三章内必须立起本卷冲突目标。
3. **章末钩子三型**（每章钩子归入其一，可叠加）：
   - 悬念钩：留下未解之谜、身份疑点、文本异象；
   - 危机钩：敌手逼近、变故爆发、期限将至；
   - 目标钩：藏宝现世、新行程、新承诺。
4. **张弛有度**：连续高强度章节不超过 3 章；两个小高潮之间至少安排 1 章慢节奏过渡（养关系、做储备、回收伏笔）。慢章同样必须推进剧情或深化人物，不许借慢章讲设定。
5. **快慢语感**：战斗、对峙、剧变动用短句与对话推进；内心、渲染、博弈可用长句与描写。单章内长短交替，避免通篇高八度或通篇平铺。

## 规则三：补字数的合法手段与注水禁令

1. **触发条件**：初稿章低于 1800 字下限时，只允许用下列四种手段补；高于 2600 字先删减，删不下去再考虑拆章。目标区间仍以 AGENTS.md 为准（2000–2400）。
2. **四种合法补字手段**：
   - **心理独白**：内心挣扎、回忆、算计推演，须贴合 `01-characters.md` 的人设动机；
   - **环境渲染**：光影、声音、气味、温度，环境要映射人物情绪，不做风景明信片；
   - **动作细节**：战斗关键节点的慢镜头、招式拆解、地利运用，符合"写势与巧，不堆数值"；
   - **配角反应**：围观者神色、反派微表情、队友接应，须在不切换主视角的前提下写出（遵守 AGENTS.md 第六节第 7 条）。
3. **注水四禁**：对话重复车轱辘；与剧情无关的风景凑字；复述前文情节刷字；设定说明文式罗列。审计发现任一注水，退回重写。
4. **密度优先**：四种手段用尽仍不达上限的，宁可落在 1800–2000 下限，不许硬凑。

## 规则四：写前逻辑自检清单（六查）

每章动笔前对照数据源与上一章末状态逐项过一遍；审计环节将本清单列为固定检查项：

1. **查伏笔**：本章按 `09-consistency.md` 台账应回收、应呼应的伏笔是否处理？新埋的是否当场登记？
2. **查状态**：出场人物的伤势、物品、境界、位置与上一章末是否一致？伤势必须有恢复过程或后遗症，不许瞬间痊愈。
3. **查物品**：前文新获之物是否被使用、展示或交代明确去处？不许凭空消失。
4. **查情绪**：大事件后的情绪流转是否自然（愤怒之后是冷静，喜悦之后是警惕），不许无因换脸。
5. **查智商**：反派行动是否有合理动机与手段？以弱胜强是否有计谋、资源或代价支撑？境界压制不许口头解释。
6. **查时间**：与 `04-timeline.md` 是否对齐？闪回、别章插叙的时间点是否明确不混乱。

## 规则五：伏笔埋设三技法

登记与回收仍以 `09-consistency.md` 台账为准，以下为写作层面手法：

1. **草蛇灰线**：早期放一个不起眼的细节，后期成为关键解法。细节要自然长在场景里，不能刻意亮给读者。
2. **红鲱鱼**：故意把读者引向错误真相。仅限叙事视角人物当时确实会误解的"错答案"，不允许叙述层面对读者撒谎。
3. **回声效应**：同一意象或台词在关键节点反复出现，跨章呼应强化主题。每次回响点位登记入台账，防止烂尾失联。

## 规则六：人物弧光六阶

用于 201–1200 扩展中的主要人物与新增重要配角的成长路线设计，设计结果落位 `01-characters.md` 人物卡，不在正文里宣讲：

缺陷（内心弱点）→ 需求（真正欠缺之物）→ 抗拒（坚持旧观念）→ 觉醒（重大事件触发反思）→ 成长（开始改变）→ 圆满（克服缺陷或付出应有代价）。弧光跳转必须由 `03-events.md` 中的重大事件触发，不做无因转变；未走完弧光的人物不许提前"圆满"。

## 规则七：来源与边界（明确不采纳项）

借鉴技能时以下内容**明确不采纳**，后续任何回导或参考不得再次引入；如确需采纳，须用户单独指令：

1. **第一人称"我"视角**：本作为第三人称有限视角，视角切换按 AGENTS.md 写作铁律第 7 条执行。
2. **章末"作者说"互动体**：本作正文与卷文件不附读者互动文案。
3. **违禁词机械替换**（杀→陨落、死→魂飞魄散、血→猩红等）：本作靠"写势不堆数值"的笔法控制暴力呈现，不做同义机械替换。
4. **2200–2500 硬字数指标**：本作字数标准以 AGENTS.md 的 1800–2600（目标 2000–2400）为准。
