# 《九州烟云》战力与成长体系整合草稿

> **用途**：续写（自第 54 章起）的战力/成长事实基线，防战力崩坏。
> **事实源**：`九州烟云-ai-context/`（01-characters 五维数值、07-items、11-writing-log 卷一口径、AGENTS.md 铁律）。冲突时以数据源为准。
> **快照基准**：截至第 56 章；青云剑意后三重命名「持·藏·明」（56 章批次补拟，见 09 变更记录 9）。

## 一、实力标尺：五维数值体系（出处：01-characters.md）

- 全书人物战力以**五维数值（0–100）**标定：力量/智谋/魅力/意志/机缘。数据源未设"炼气筑基"式境界等级，**严禁擅自引入数值化境界体系**。
- 参照系（力量维）：夜枭 70 < 叶惊寒 80 ≈ 慕长风 82 < 姒媚 82 < 霍山河 84 < 洛惊鸿 88 < 铁牛 88（横练）< 屠九 90 < 苍梧真人 90 < 玄清子 95 < 殷无涯 99 ≈ 秦老（残魂）99。
- **林霄当前五维（01 档开篇值）**：力量 78 · 智谋 62 · 魅力 70 · 意志 88 · 机缘 92。注意：这是全书档案值；实际战斗中林霄 78 的硬实力对上 90+ 高手（屠九）仍需剑诀进阶＋剑令合一补差（第 108 章首败屠九即为此设计，出处：10-outline）。
- 战斗描写纪律：**写"势"与"巧"，不堆数值**（AGENTS.md 铁律 5）。

## 二、青云剑宗修行晋升线（出处：01-characters 林霄成长线 / 卷一正文）

- **宗门等级**：杂役 → 外门 → 内门 → 亲传（问剑峰）。林霄节点：杂役（3 章）→ 春考入外门前百（7 章，第 47 名）→ 内门选拔第十九名（9–10 章）→ 问剑峰亲传第一人（11 章拜师）。
- **青云剑意核心口诀**："不在高，在**直**"（27 章师父出关所授）；53 章赐后三重心法（玄清子亲授，尚未展开，为 54–66 章修行素材）。
- 《青云剑典》（镇派总纲，藏经阁）＋青莲剑诀正篇合流＝第 81 章《封山冬训》的进阶关口（尚未写）。

### 其他剑法/兵器谱（出场需对号）

- **听雨一百单八式**：慕长风原剑法（10 章"四招破听雨"）。
- **听潮**：慕长风新剑（听雨重铸，42 章命名）；收势朝东南（叛向幽冥的暗线）。
- **镇脉秋水剑**：洛惊鸿亲授慕长风的决赛兵器（51 章，师徒羁绊重场）。
- **《回风三叠》**：慕长风代授、气路暗藏**逆行心关之坑**；林霄识破绕行，"坑就成了我的路"，决赛反用（19 章埋 → 51–52 章收）。
- **叠浪剑**（沈青崖）、**剑丸**（周明礼）、**缚剑/分缠劲**、**寒潭三百提按**（洗剑池练腕）等支线技法，出处：08-chapters。
- **横练**：铁牛一途（横练金身，88 力量）；110 章"横练金身小成"（未写）。
- **问水**：玄清子所授未开锋剑胚（11 章）；**青莲剑**：31 章认主，剑身青莲纹、遇血则鸣（别名"钥锋"，三钥之一）。

## 四、幽冥功法体系（出处：06/07 号文件＋卷一正文）

- **幽冥鬼气**：屠九级战力攻击附带反噬根伤；玄清子中此伤贯穿卷一至 42 章服丹渐稳（根治需九转续脉丹）。
- **采魂术**：分"急性采魂"（尸傀）与"慢性采魂"（引魂钉长期吸魂，36 章谷中怪病即此）——手法与二十年前盗《青囊残卷》同源（"采"字诀，18 章）。
- **借尸炼魂**：血魂幡分幡采活人魂（24 章黑风隘石窑）；"幡物勿毁，**魂可渡**"（23 章玄清子字条，与终局"渡"主题呼应）。
- **血魂大阵/血魂幡**：聚生魂开九幽之眼；阵眼九幽台；幡展血月悬空（未成，当前 53 章仅"东南暗红云线逐夜变亮"＝血月前兆）。
- **夺舍/炼血奴**：教主级手段——夺舍慕长风（156 章）、炼姒媚为血奴（120 章）——**均尚未发生**，当前进度下不得提前使用。
- **尸傀**：幽冥教基础战力；掘地寻令、护窑巡逻的耗材。

## 五、医道体系（出处：07-items / 05-locations）

- **药王谷**：医道圣地；九转续脉丹＝续命固本至高丹药，专治鬼气根伤；开炉需护炉，**护炉代价＝护炉者经脉受损**（41 章映雪第一炉，已发生；158 章第二炉，未写）。
- **回春丹**：映雪所炼疗伤圣药，吊住重伤者一缕生机（存量三枚）。
- **《青囊残卷》**：上古医道总纲、三钥之"钥引"，内藏**续魂之法**（终战渡魔关键）。当前进度：上半卷未寻回（85–86 章破案）、下半卷未现世（96 章万宝楼流出）。
- **雪魄散**：映雪药引（17 章上山解刀毒）。
