# 设计稿 —— 视觉设计规范（Hi-Fi Design Spec）

> 基调：参考用户提供的运动数据大屏 —— **深色底 + 紫→品红→蓝渐变圆角主面板 + 玻璃拟态卡片 + 大字号白色数字**。
> 情绪：专业、沉浸、有一点"作战室"的仪式感。所有颜色/圆角/阴影以本稿 token 为唯一事实源（实现于 `src/styles/tokens.css`）。

## 2. 字体与字号

- 字族：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`；数字用 `font-variant-numeric: tabular-nums`。
- 比例：页面标题 22/600；卡标题 15/600；正文 14/400；辅助 12/400；**数据大数字 28–40/700**（参考图 "84""82.3%" 的气势）。
- 行高 1.6；正文白 `.92`。

## 5. 关键页面视觉

### 5.1 人物"白底占位"（用户指定）

无形象图的人物，所有出现处（卡片墙/图谱节点/详情/英雄卡）使用：
- 白底（`rgba(255,255,255,.92)`）圆角容器；
- 居中**剪影 SVG**（头圆 + 肩弧，`#B9AEE0` 20% 透明度）；
- 底部小字"暂无形象"（详情/大卡才显示，小卡片省略）；
- 详情内整卡可点击上传，上传后图片 `object-fit: cover` 圆角裁切。

### 5.2 总览英雄卡

左 1/3 形象区（人物大图允许溢出卡片顶部 40px，复刻参考图球员悬浮效果：`filter: drop-shadow(0 24px 32px rgba(0,0,0,.4))`）；中部姓名 32/700 + 势力 Tag + 数据行；右侧五维雷达（线框 `rgba(255,255,255,.25)`，填充 `rgba(201,166,255,.25)`，描边 `#C9A6FF`）。下方四枚玻璃统计卡（图标 + 标签 + 大数字），其一用 `--accent` 实底（待处理提示数）。

### 5.3 实体高亮（正文预览）

已登记实体：圆角 6 色底 16% + 色字 + 1px 同色 40% 描边；未登记名词：无底色，**2px 琥珀虚线下划线**（`border-bottom:2px dashed var(--accent-2)`），hover 出现操作气泡（琥珀边玻璃卡）。

### 5.4 图谱画布

画布容器玻璃卡内嵌，背景叠加淡网格（`rgba(255,255,255,.04)` 40px 方格）；节点 = 圆 + 形象图裁切（无图白底剪影）；边 `rgba(255,255,255,.28)`，hover 邻居提亮、其余降为 `.08`；图例固定左下角玻璃胶囊条。

### 5.5 动效

| 场景 | 规格 |
| --- | --- |
| 卡片 hover | translateY(-2px) + `--glass-strong`，160ms ease-out |
| 弹窗进出 | 180ms scale .96→1 + fade |
| 警示卡 | 琥珀左边条 + 首次出现 pulse 一次（600ms） |
| 图谱节点 | 进场 d3 力导向自然收敛，无需额外动画 |
| 页面切换 | 内容区 120ms fade，不做花哨转场 |
