# 设计稿 —— 视觉设计规范（Hi-Fi Design Spec）

> 基调：**Resonance HUD —— 深色金调游戏 HUD**（近黑基底、单一品牌金强调色、发丝级描边、纯直角、L 形四角角标、中英双语区块标题）。所有颜色/几何/阴影以本稿 token 为唯一事实源，实现于 `src/styles/tokens.css`；品牌资产（图标/安装器，见《06 部署指南》）与之同源。
> 情绪：像一台作战 HUD —— 克制、精密、沉浸，金色发丝线在近黑底上如仪表读数。
> 历史：早期方案为“紫→品红→蓝玻璃拟态大屏”，已全面替换为 HUD；旧令牌名（`--glass`/`--accent`/`--radius-card` …）在 `tokens.css` 里全部重定向到 HUD 值，勿再按旧语义取字面值。

## 1. 色彩 Tokens

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg-outer` | `#0c0d10` | 页面最外层 |
| `--bg-0` | `#14161a` | 面板/近黑基底 |
| `--bg-1` | `#1b1e23` | 浮起层/弹层底 |
| `--card`（旧 `--glass`） | `rgba(255,255,255,.035)` | 卡片填充（极淡提亮，非彩色玻璃，无 blur） |

| `--gold-bright` / `--accent-2` | `#e6cf95` | 高亮金（激活/链接/次强调/未登记名词虚线） |
| `--gold-dim` / `--glass-line-hi` | `rgba(201,172,103,.3)` | 弱化金（聚焦描边、hover） |

| `--text-mid` | `rgba(250,250,233,.72)` | 次文本 |

| `--danger` | `#ff6b6b` | 危险/死亡/告警 |

实体内容色（**数据编码**，非装饰；图谱节点、正文实体标签、雷达图用，通过 `--tag-c`/`--c`/`--theme` 注入）：人物 `#c9a6ff` · 地点 `#6fe3d0` · 物品 `#ffd37a` · 事件 `#ff9e7a` · 势力 `#7fb0ff`。

**强调色纪律**：界面只允许金色一个强调 hue；实体色仅出现在承载数据的内容表面（节点/标签/雷达/角标），不铺大面积底、不作按钮主色。

## 2. 字体与字号

- 双语字族：**中文** `system-ui, "PingFang SC", "Microsoft YaHei"`；**拉丁/数字** `--hud-latin = "Bahnschrift","DIN Alternate","Segoe UI", sans-serif`——用于区块英文副标（`EXPORT`/`LIVE SYNC · DESKTOP` 等）、计数与大数字，配 `font-variant-numeric: tabular-nums`。
- 中英区块标题：中文主标题 + 小号 `letter-spacing` 拉丁英文副标（`.head-en` / `.page__en`），HUD 取景框感的核心。
- 比例：页面标题 22/700；卡标题 15/600（+ 英文副标）；正文 14/400；辅助 12/400；数据大数字用拉丁体 + 大字距。
- 行高 1.6–1.85；正文暖白。

## 3. 几何与阴影（纯直角是 HUD 的灵魂）

| Token | 值 |
| --- | --- |
| `--radius-panel` / `--radius-card` / `--radius-sm` / `--radius-pill` | **全部 `0`**（纯直角，零圆角） |
| 描边 | 发丝级 1px `--hair`；激活/聚焦转 `--gold-dim`（不做顶部高光渐变、不做外发光圆环） |
| `--shadow-card` | `0 14px 34px rgba(0,0,0,.45)`（近黑深投影，无彩色辉光） |
| `--shadow-pop` | `0 20px 60px rgba(0,0,0,.6)` |
| `--hud-ease` | `cubic-bezier(.32,.72,.24,1)`（统一缓动） |
| 间距阶 | 4 / 8 / 12 / 14 / 16 / 18 / 20 / 24 |

面板配方（关键质感，取代旧玻璃拟态）：
```css
/* 深色金调 HUD 面板：近黑底 + 顶部一条极淡金雾 + 发丝描边 + 纯直角 */
background-color: var(--bg-0);
background-image: radial-gradient(130% 60% at 100% 0%, rgba(201,172,103,.07), transparent 60%);
border: 1px solid var(--hair);
border-radius: 0;
box-shadow: 0 16px 44px rgba(0,0,0,.4);
/* 转角 L 形四角角标 / 菱形节点用描金 SVG 或 ::before/::after，营造 HUD 取景框感 */
```

## 4. 核心组件规范

| 组件 | 规范 |
| --- | --- |
| 主按钮 | 深底 + 1px 金发丝描边、纯直角、`letter-spacing`；主 CTA = 半透明金底 + 金字，hover 提亮到 `--gold-bright`；危险 = 红字红边 |
| 顶部导航图标钮 | 方格图标、纯直角；**激活 = 金色左边条 + 金图标 + 极淡金雾底**（不再是白底深色图标） |
| 输入框 | 纯直角、深底、1px `--hair`；聚焦描边转 `--gold-dim`，无外发光圆环 |
| 标签 Tag | 实体色描边 + 同色文字、透明底、纯直角（色仅作数据编码） |
| 弹窗 | `--glass-dark` 近黑底 + 金发丝边 + `--shadow-pop`，纯直角；遮罩 `rgba(8,9,12,.66)` |
| Toast | 深色直角条，左侧状态色条：成功 `--ok` / 警告 `--gold-bright` / 错误 `--danger` |
| 状态徽标 | 纯直角 chip：金/绿/红描边 + 同色字（如 `已回收` / `通过` / `告警`） |
| 空态 | 虚线 `--hair` 直角框 + 线描插画 + 引导按钮 |
| 表格行卡 | 深底、行 1px 发丝分隔、hover 极淡金雾提亮；表头金字大写小字距 |

## 5. 关键页面视觉

### 5.1 人物"白底占位"（用户指定）

无形象图的人物，所有出现处（卡片墙/图谱节点/详情/英雄卡）使用：
- 白底（`rgba(255,255,255,.92)`）圆角容器；
- 居中**剪影 SVG**（头圆 + 肩弧，`#B9AEE0` 20% 透明度）；
- 底部小字"暂无形象"（详情/大卡才显示，小卡片省略）；
- 详情内整卡可点击上传，上传后图片 `object-fit: cover` 圆角裁切。

### 5.2 总览英雄卡

左 1/3 形象区（人物大图允许溢出卡片顶部 40px，复刻参考图球员悬浮效果：`filter: drop-shadow(0 24px 32px rgba(0,0,0,.4))`）；中部姓名 32/700 + 势力 Tag + 数据行；右侧五维雷达（线框 `rgba(255,255,255,.25)`，填充 `rgba(201,166,255,.25)`，描边 `#C9A6FF`）。下方四枚玻璃统计卡（图标 + 标签 + 大数字），其一用 `--accent` 实底（待处理提示数）。

### 5.3 实体高亮（正文预览）

已登记实体：圆角 6 色底 16% + 色字 + 1px 同色 40% 描边；未登记名词：无底色，**2px 琥珀虚线下划线**（`border-bottom:2px dashed var(--accent-2)`），hover 出现操作气泡（琥珀边玻璃卡）。

### 5.4 图谱画布

画布容器玻璃卡内嵌，背景叠加淡网格（`rgba(255,255,255,.04)` 40px 方格）；节点 = 圆 + 形象图裁切（无图白底剪影）；边 `rgba(255,255,255,.28)`，hover 邻居提亮、其余降为 `.08`；图例固定左下角玻璃胶囊条。

### 5.5 动效

| 场景 | 规格 |
| --- | --- |
| 卡片 hover | translateY(-2px) + `--glass-strong`，160ms ease-out |
| 弹窗进出 | 180ms scale .96→1 + fade |
| 警示卡 | 琥珀左边条 + 首次出现 pulse 一次（600ms） |
| 图谱节点 | 进场 d3 力导向自然收敛，无需额外动画 |
| 页面切换 | 内容区 120ms fade，不做花哨转场 |
