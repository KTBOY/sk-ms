# 原型稿 —— 页面布局与交互流（Lo-Fi Wireframe）

> 说明：本稿为低保真线框 + 交互流说明；高保真视觉规范见《04-设计稿》。
> 全局框架：深色底 + 全屏圆角渐变主面板（参考用户提供的运动数据大屏风格）。

## 0. 全局框架

```
┌────────────────────────────────────────────────────────────────────┐
│ 深色底(#16122B)，四周 24px 留白                                     │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │ 紫→品红→蓝 渐变圆角主面板(radius 24)                          │  │
│  │ ┌────┐      ╭──────────────────────────╮   ┌──────────────┐ │  │
│  │ │Logo│      │ 玻璃图标导航(总览/写作/人物/  │   │ 搜索  ⚠4 头像 │ │  │
│  │ └────┘      │ 图谱/事件/时间线/地点/势力/物品│   └──────────────┘ │  │
│  │             ╰──────────────────────────╯                      │  │
│  │ ┌──────────────────────────────────────────────────────────┐ │  │
│  │ │                页面内容区（滚动）                          │ │  │
│  │ └──────────────────────────────────────────────────────────┘ │  │
│  └──────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

- 顶部导航：图标按钮玻璃胶囊，**激活态 = 白底深色图标**（复刻参考图 Home 键样式）。
- 全局搜索：联想实体（人物/事件/物品/地点/势力），回车直达详情。
- 右上警示铃：一致性体检问题数红点，点击弹体检清单。

## 2. 写作台（核心页）

```
┌──────────┬──────────────────────────────────┬───────────────────┐
│ 章节列表  │ 第一章·拜入青云门     [编辑|预览] │ 页签:一致性|上下文 │
│ ●序1 第一章│ ┌──────────────────────────────┐ │ ┌───────────────┐ │
│  草稿 1.2k│ │ 正文编辑区(textarea)          │ │ │⚠未找到「赵管事」│ │
│ ○序2 第二章│ │  "林霄抬剑……"                │ │ │出现5次         │ │
│  写作中 3k│ │                               │ │ │[设为人物][别名]│ │
│ ○序3 ……  │ │                               │ │ │[忽略]          │ │
│ [+ 新章节] │ └──────────────────────────────┘ │ ├───────────────┤ │
│ 上移/下移/删│ 字数 1024 · 自动保存 ✓           │ │已引用: #林霄    │ │
└──────────┴──────────────────────────────────┴───────────────────┘
预览模式：实体着色标签；未登记名词=琥珀虚线下划线，点击 → 气泡操作
```

**关键交互流：未登记名词三步闭环**
```
输入"赵管事" → 右栏琥珀卡(次数+疑似相似:赵德海82%)
  ├ [设为人物]     → 弹快速建档(预填姓名) → 保存 → 正文高亮变紫
  ├ [登记为别名]   → 选目标实体 → 该词此后识别为"林霄"
  └ [加入忽略词表] → 卡片消失，不再提示
```

**上下文包页签**
```
┌─────────────────────────┐
│ # 本章上下文包           │
│ ## 出场人物 卡片×3        │
│ ## 地点/物品 摘要        │

│ ## 写作要求(防崩条款)     │

└─────────────────────────┘
```

## 8. 状态设计清单

| 状态 | 设计 |
| --- | --- |
| 空态 | 白底剪影占位(人物) / 虚线玻璃卡 + 引导按钮(各列表) |

| 危险操作 | 红色文字按钮 + 确认弹窗 |
