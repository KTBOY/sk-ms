# 06 · 部署指南

项目为纯前端 SPA，`dist/` 即全部产物，可托管到任何静态站点服务。

## GitHub Pages（已配置自动发布）

仓库已包含 `.github/workflows/deploy-pages.yml`：推送到 `main` 分支即自动构建并发布到 Pages。

首次部署步骤：

1. 在 GitHub 上新建一个仓库（如 `novel-atlas`，公开）。
2. 本地执行：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 稍等 Actions 跑完，访问 `https://<你的用户名>.github.io/<仓库名>/`。

之后每次 `git push` 都会自动重新发布。

> 说明：应用无前端路由（页内 Tab 切换），vite `base: './'` 相对路径同时兼容 Pages 子路径与 Electron `file://` 加载，无需改动。仓库中不含任何密钥；AI 接口配置只存在访问者浏览器本地。

## 其他静态托管（Vercel / Netlify / Cloudflare Pages）

- 构建命令：`npm run build`
- 产物目录：`dist`
- 无需其他配置（根路径部署，`base: './'` 同样可用）

## Electron 桌面应用

```bash
npm run app:build   # 产出 release/ 下的 NSIS 安装包与便携版
```
